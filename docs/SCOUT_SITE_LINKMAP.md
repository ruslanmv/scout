# Scout site — link & route map

Authoritative map of the multi-page Scout product, generated by
`scripts/build_scout_site.py` and served under the project's Pages base path
**`/scout/scout/`** (the React landing is `/scout/scout/`; everything else is its
own route with its own `index.html`).

> Correction to a common assumption: the report **sections are separate pages**
> (e.g. `/report/overview/`), **not** `#hash` anchors, and the report itself lives
> at `/report/`, not at the site root. The root (`/scout/scout/`) is the landing.

## Report state (carried across links)

Report pages are personalized client-side (`scout-site.js`) from the query
string, and every internal `data-keepq` link preserves it:

```
?country=Italy&city=Rome&goal=build_portfolio&profile=developer
```

## The "become" generator (report ending → My Learning)

At the bottom of `/report/` a **“Create a new learning path”** block asks *what do
you want to become?* (target role + objective + optional focus areas). On submit
it hands off to the Learning Navigator, which runs the real deterministic
pipeline (with an offline demo fallback), then lands the learner in My Learning:

```
/report/
  └─ submit "become" (role, goal, focus, + report's country/city)
       → /learn/?intent=advance_career&role=<role>&goal=<goal>
                 &country=<country>&city=<city>&focus=<csv>&start=1
            → (auto) generate path + save to localStorage
                 → /my-learning/path.html?id=<localId>
```

The learn page reads these params (`initFromQuery`), prefills the wizard, and —
when `start=1` — auto-generates and transfers without extra clicks. Because the
Navigator falls back to deterministic demo data when no API is reachable, the
whole chain works on the static Pages site; when the FastAPI backend is live
(with an OllaBridge key, see below), it uses real data.

## API routes the frontend calls (when a backend is present)

`/learn/` and `/my-learning/` call `…/api/v1/learning/*`
(`goals/resolve`, `paths`, `skill-gap`, `paths/{id}/replan`) and degrade to demo
data on the static site. The gateway key for live AI is read server-side from
`SCOUT_AI_API_KEY` / `SCOUT_LLM_API_KEY` / `OB_TOKEN` (never exposed to the
browser).
