# Data Sources

Initial sources:

- GitHub public API
- GitHub location search inspired by committers.top
- Hugging Face public API
- RSS/news feeds
- Curated job/community placeholders

Future sources:

- public job boards and skills datasets,
- conference agendas,
- community events,
- research feeds,
- Stack Overflow and developer forums where terms permit.

These signals feed the ranking; the live study/build/publish plan is then synthesized by the AI advisor (OllaBridge Cloud) — see [AI_AND_ADMIN.md](AI_AND_ADMIN.md).
