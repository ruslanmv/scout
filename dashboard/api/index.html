API documentation

Use Scout endpoints to retrieve trends, reports, recommendations, topic details, and dataset metadata.

Reports

/api/v1/ui/bootstrap builds the report payload used by the static pages when the backend is available.

Topics

/api/v1/topics/{topic}/deep-dive returns evidence, study plans, projects, and risk notes for a topic.

Datasets

/api/v1/datasets exposes generated snapshots and metadata for machine consumers.

Health

/api/v1/health checks service availability for integrations and monitors.
