FOR DEVELOPERS

Run Scout your way.

Verified entry points: local FastAPI service, REST API and optional MCP server.

git clone https://github.com/ruslanmv/scout.git
cd scout
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/generate_snapshot.py
python -m uvicorn app.main:app --reload
curl "http://127.0.0.1:8000/api/v1/ui/bootstrap?country=Italy&city=Rome&goal=build_portfolio&profile=developer"
python -m pip install -e ".[mcp]"
python -m scout_mcp
Python 3.10+ · Local API docs at http://127.0.0.1:8000/docsFull setup & troubleshooting ↗
